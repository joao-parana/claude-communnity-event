de mercado (2022–2026) — insumo direto para qualquer solução de custo/compras.

## 3. Dados abertos — `data.rio` e ArcGIS REST

**Portal:** https://www.data.rio
**Gestor:** Instituto Municipal de Urbanismo Pereira Passos (IPP)
**Licença dos datasets de educação:** CC-BY 4.0 — atribuir "Prefeitura da Cidade do Rio de Janeiro"

### 3.1 Endpoints testados e funcionais

| Camada | Endpoint | Registros |
| --- | --- | --- |
| Limites das CREs | `https://pgeo3.rio.rj.gov.br/arcgis/rest/services/Educacao/SME/MapServer/0` | 11 |
| **Escolas Municipais** | `https://pgeo3.rio.rj.gov.br/arcgis/rest/services/Educacao/SME/MapServer/1` | **1.590** |
| Microáreas SME | `https://pgeo3.rio.rj.gov.br/arcgis/rest/services/Educacao/SME/MapServer/2` | — |
| Creches Conveniadas | `http://pgeo3.rio.rj.gov.br/arcgis/rest/services/SME/SME_View/MapServer/2` | — |

**Campos da camada de escolas:** `objectid`, `cre` (double), `designacao` (int), `denominacao`
(string 255), `tipo` (string 200), `latitude`, `longitude`.
**Projeção da geometria:** EPSG **31983** (SIRGAS 2000 / UTM 23S). Os campos `latitude`/`longitude`
já vêm em WGS84 decimal — use-os e evite reprojeção.
**Última atualização do dado:** junho/2023.

Exemplo de consulta:

```bash
curl -s "https://pgeo3.rio.rj.gov.br/arcgis/rest/services/Educacao/SME/MapServer/1/query?where=1%3D1&outFields=*&resultRecordCount=2000&f=pjson"
```

Contagem apenas:

```bash
curl -s "https://pgeo3.rio.rj.gov.br/arcgis/rest/services/Educacao/SME/MapServer/1/query?where=1%3D1&returnCountOnly=true&f=pjson"
```

### 3.2 Busca de datasets no portal

A UI do `data.rio` é uma SPA (scraping direto do HTML não rende). Use a **API de busca**:

```bash
curl -s --get "https://www.data.rio/api/search/v1/collections/dataset/items" \
  --data-urlencode "q=educação" --data-urlencode "limit=20"
```

O campo `properties.url` de cada *feature* traz o endpoint ArcGIS quando existe;
`properties.description` traz a descrição completa (a camada de escolas, por exemplo, documenta ali o
*breakdown* por tipo de unidade).

### 3.5 As 11 CREs — área e densidade de unidades

Extraído da camada de limites (`MapServer/0`) cruzado com a contagem de unidades de ensino.
A **densidade** muda radicalmente a natureza de qualquer problema logístico (merenda, transporte,
visitas de busca ativa, manutenção):

| CRE | Área (km²) | Unidades de ensino | Unidades / km² |
| --- | ---: | ---: | ---: |
| 1ª | 34,4 | 96 | 2,79 |
| 2ª | 100,4 | 153 | 1,52 |
| 3ª | 44,2 | 136 | 3,08 |
| 4ª | 40,1 | 162 | 4,04 |
| 5ª | 46,1 | 130 | 2,82 |
| 6ª | 31,7 | 111 | 3,50 |
| 7ª | 293,8 | 174 | 0,59 |
| 8ª | 116,6 | 193 | 1,66 |
| 9ª | 138,8 | 165 | 1,19 |
| 10ª | **316,7** | 193 | **0,61** |
| 11ª | 41,5 | 43 | 1,04 |

A **10ª CRE** (Santa Cruz / Sepetiba, 316,7 km²) e a **7ª** (Campo Grande, 293,8 km²) somam
**52% da área** da rede com apenas 24% das unidades — sete vezes mais espalhadas que a 4ª CRE.
Qualquer roteirização, entrega ou visita domiciliar tem custo unitário muito diferente entre elas.

Campos da camada de limites: `objectid`, `nome` ("1ª CRE"…), `codigo` ("01"…), `globalid`,
`st_area(shape)` (m²), `st_length(shape)` (m). Geometria em polígonos; o comando `cres` do
`rio_crawler.py` já reprojeta para WGS84.
